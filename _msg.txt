Give the quiz options

Every question shipped with a bare answer letter and no options behind
it, so section 16 rendered as five stems followed by "Answers: b - ...".
Question 3's explanation even referred to options A and B that were never
written down.

- options are tappable rows; the right one is marked either way, the
  wrong pick is struck through, and the explanation opens
- one answer per question; options disable after a tap
- fixed a collision I introduced while doing this: the option label was
  emitted as span.t and picked up the glossary tooltip styling, so every
  option had a dotted underline and a dead tooltip
- renamed the desk tooltip class .t to .term at the root; a one-character
  class name collides with anything and no lint can guess what is safe
- build now rejects a quiz question with no opts, an answer key that is
  not one of the opts, or fewer than two options
- test_classes.py checks every class the page uses has a CSS rule
